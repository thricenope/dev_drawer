专业级多平台 UI/UX 设计智能体 skill。本质是"一个可检索的设计数据库"——内置样式、色板、字体搭配及 UX 准则，AI 提 UI 需求时自动触发，匹配合适的设计体系并直接产出符合最佳实践的代码。作者 **nextlevelbuilder**，兼容 Claude Code / Cursor / Windsurf。

## 数据规模
- **67** 种 UI 风格
- **96** 个行业调色盘
- **57** 组 Google Fonts 字体搭配
- **25** 种常用图表类型
- **99** 条 UX 指导原则（含可访问性 / 性能规范）
- **100** 条行业专项推理规则
- 支持 **13** 个技术栈（React / Next.js / Vue / Tailwind / Flutter / SwiftUI 等）

## 安装
- Claude 插件市场 / npx / 官方 CLI 均可
