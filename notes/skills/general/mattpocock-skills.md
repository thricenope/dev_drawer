Matt Pocock 的工程实践 skill 集。理念是"为真实工程服务，而非 vibe coding"——小巧、易改、可组合，适用于任何模型。核心解决 AI 编程的常见失败模式（沟通错位、代码冗长、质量低、架构腐化），把传统软件工程原则转成可重复的实践。

> ⚠️ 注意：这个 repo 里**没有**叫 "superpower" 的 skill。"superpower" 一般指另一个项目 [obra/superpowers](./obra-superpowers.md)。

## Skills 一览（按调用方式分）

**用户调用 `/`**
- `ask-matt` — 路由器，问哪种 skill/流程最合适
- `grill-with-docs` — 盘问式提问同时构建领域模型，更新 CONTEXT.md / ADR
- `triage` — 用状态机处理 issue
- `improve-codebase-architecture` — 扫描可"深化"的模块，生成 HTML 报告
- `to-spec` / `to-tickets` — 当前对话转规范 / 拆成示踪子弹票据
- `implement` — 按规范/票据构建，驱动 /tdd 并在提交前 /code-review
- `wayfinder` — 把庞大工作规划成决策票据图谱
- `grill-me` — 无情采访直到计划每个分支都解决
- `handoff` — 压缩成移交文档给下一个代理
- `teach` — 多会话教学
- `to-questionnaire` — 把决策变成给专家的问卷
- `wait-what` — 没听懂时用通俗英语重新表述

**模型自动调用**
- `prototype` · `diagnosing-bugs` · `research` · `tdd` · `domain-modeling`
- `codebase-design` · `code-review` · `resolving-merge-conflicts` · `wizard`
- `grilling` · `writing-for-agents`
