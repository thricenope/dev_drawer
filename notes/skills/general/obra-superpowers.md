Jesse Vincent（Prime Radiant 团队）出品的 AI 编程技能框架 + 软件开发方法论。核心目标是让 AI **不再盲目写代码**：主动询问真实意图 → 梳理设计规格 → 创建细粒度计划 → 严格执行 TDD / 子代理驱动 / 自动审查，从而让 AI 能自主、不跑偏地连续工作数小时。

## 主要 Skills
**测试**
- `test-driven-development` — 强制红-绿-重构循环

**调试**
- `systematic-debugging` — 4 阶段根本原因流程
- `verification-before-completion` — 声明完成前确保真修好

**协作与流程**
- `brainstorming` — 写码前苏格拉底式提问完善设计
- `writing-plans` — 拆成每项 2-5 分钟的任务
- `executing-plans` — 带阶段检查点的批量执行
- `dispatching-parallel-agents` — 并发子代理工作流
- `requesting-code-review` / `receiving-code-review` — 代码审查的请求与回应
- `using-git-worktrees` — 用 git worktree 做隔离并行开发
- `finishing-a-development-branch` — 分支清理与合并/PR 决策
- `subagent-driven-development` — 两阶段审查（规范合规 + 代码质量）

**元技能**
- `writing-skills` — 创建新 skill 的指南
- `using-superpowers` — 入门介绍
